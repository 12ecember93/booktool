Dán URL ảnh

Tùy chọn đầu ra

Dùng làm tên file ZIP.

Chọn một cách tải. File .bat chỉ chạy trên Windows; Android không chạy trực tiếp file này.

Sao chép mã bên dưới rồi chạy trong Console của tab trang sách.

Nếu tải trực tiếp bị CORS chặn, dùng “Code tải ZIP” trên tab trang sách hoặc file .bat trên Windows.

Hướng dẫn nhanh
Dán danh sách URL vào ô duy nhất bên trái. ZIP được tạo ngay trên trình duyệt nếu website cho phép tải ảnh.

      
1
Sao chép mã lấy URL
Mã này dùng để tìm URL ảnh trên trang sách đang mở.
Xem mã Console
(() => {
  const html = document.documentElement.outerHTML.replace(/\\\\\//g, "/");
  const found = html.match(/https?:\\/\\/[^"'<>\\s]+/g) || [];
  const urls = [...new Set(found.map(u => u.replace(/[),;\\]}]+$/, "")))].filter(u => /\\.(png|jpe?g|webp|gif|avif)(\\?|$)/i.test(u) || /-page-\\d+-/i.test(u));
  copy(urls.join("\\n"));
  console.log("Đã copy " + urls.length + " URL ảnh vào clipboard.");
})();

      
2
Chạy mã trong trình duyệt
Làm lần lượt các bước dưới đây trên máy tính. Trên điện thoại, thao tác Console thường không khả dụng; hãy mở trang sách trên máy tính.
  1. Mở trang sách và chờ các trang ảnh tải xong.
  2. Nhấn F12 để mở Developer Tools / Công cụ dành cho nhà phát triển. Nếu không thấy, thử các cách bên dưới theo trình duyệt bạn đang dùng.
  3. Trong cửa sổ vừa mở, bấm tab Console. Nếu cửa sổ mở ở cạnh phải hoặc phía dưới màn hình thì vẫn đúng.
  4. Quay lại tab Get images to ZIP tool và bấm một trong hai nút Copy code. Dòng trạng thái cần báo Đã sao chép MÃ JAVASCRIPT.
  5. Quay lại tab trang sách. Bấm vào dòng nhập ở cuối tab Console, nhấn Ctrl + V (Mac: Cmd + V) để dán mã.
  6. Nhấn Enter để chạy. Nếu Chrome/Edge cảnh báo không cho dán, chỉ làm theo hướng dẫn trên màn hình nếu bạn hiểu và tin tưởng mã; không dán mã lạ từ nguồn không tin cậy.
  7. Chờ kết quả. Console sẽ hiện thông báo số URL ảnh tìm được và cố gắng sao chép danh sách URL vào clipboard.
  8. Quay lại tab công cụ, dán danh sách URL vào ô duy nhất.
  9. Bấm Tạo mã tải ZIP trên trang sách, rồi quay lại tab trang sách → Console → dán mã vừa copy → Enter. Thanh tiến trình hiện trên trang sách và ZIP sẽ tự tải xuống.
🦊 FirefoxCtrl + Shift + K mở Console
🌐 Chrome / EdgeCtrl + Shift + J mở Console
🧭 Safari (Mac)Develop → Show JavaScript Console. Nếu chưa có Develop, bật trong Safari Settings → Advanced.

      
3
Dán và kiểm tra danh sách
Dán URL vào ô duy nhất, bấm Tạo mã tải ZIP trên trang sách, rồi chạy mã trong Console của tab trang sách.

      
Mẹo
  • Chờ sách tải xong rồi mới chạy mã.
  • URL có thể đến từ nhiều website khác nhau.
  • URL không phải ảnh sẽ được bỏ qua; URL ảnh lỗi sẽ hiện trong báo cáo.
